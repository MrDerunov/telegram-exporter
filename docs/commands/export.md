# export — Экспорт сообщений из чатов

**Назначение:** Выгрузка сообщений Telegram в JSON и Markdown с опциональной загрузкой медиа, транскрипцией и аналитикой.

Основная рабочая команда утилиты. Поддерживает экспорт одного чата или всех чатов из конфига, фильтрацию по дате и количеству сообщений, инкрементальный режим продолжения.

## Команды

### `export run`

Запускает экспорт сообщений.

**Режимы работы:**
- Одиночный чат (`--chat ID`) — экспорт указанного чата или канала
- Все чаты (`--all`) — последовательный экспорт всех чатов из `state.json`
- Продолжение (`--resume`) — дозагрузка новых сообщений с момента последнего экспорта

**Форматы вывода:**
- `json` — структурированный JSON с полной информацией о сообщениях
- `markdown` — читаемый Markdown, разбитый на файлы по N слов
- `both` — оба формата одновременно

**Фильтрация сообщений:**
- `--last N` — последние N сообщений
- `--date-from / --date-to` — диапазон дат (YYYY-MM-DD)
- `--days N` — последние N дней (вместо date-from/date-to)
- `--topic-id` — конкретный топик форума

Флаги `--last`, `--date-from`/`--date-to` и `--days` взаимоисключающие.

**Дополнительные возможности:**
- `--download-media` — скачивание медиафайлов (фото, видео, документы)
- `--transcribe` — транскрипция голосовых сообщений (требует `--download-media`)
- `--analytics` — генерация отчётов: `top_authors.md`, `activity.md`
- `--words-per-file` — размер разбивки Markdown (по умолчанию 50000 слов)

| Опция | Тип | Назначение |
|-------|-----|-----------|
| `--chat` | string | ID или username чата/канала |
| `--all` | flag | Экспортировать все чаты из конфига |
| `--output` | string | Директория для выгрузки |
| `--format` | choice | `json`, `markdown`, `both` (default: `both`) |
| `--last` | int | Последние N сообщений |
| `--date-from` | string | Начало периода (YYYY-MM-DD) |
| `--date-to` | string | Конец периода (YYYY-MM-DD) |
| `--days` | int | Последние N дней |
| `--topic-id` | int | ID топика форума |
| `--download-media` | flag | Скачивать медиафайлы |
| `--transcribe` | flag | Транскрибировать голосовые |
| `--transcriber` | choice | `local` (faster-whisper) или `deepgram` |
| `--analytics` | flag | Собирать аналитику |
| `--words-per-file` | int | Слов на Markdown-файл |
| `--profile` | string | Имя профиля |
| `--resume` | flag | Продолжить прерванный экспорт |
| `--skip-unavailable` | flag | Пропускать недоступные чаты (с `--all`) |

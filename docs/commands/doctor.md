# doctor — Диагностика окружения

**Назначение:** Проверка готовности окружения к работе утилиты.

Диагностирует все компоненты, необходимые для работы, и сообщает о проблемах. Полезна при первичной настройке и при возникновении ошибок.

## Проверяемые компоненты

| Компонент | Что проверяется |
|-----------|----------------|
| Python | Версия интерпретатора |
| Конфиг | Наличие `config.json` |
| Состояние | Наличие `state.json` |
| Keyring | Доступность системного keyring (недоступен в headless-окружениях) |
| Сессия | Валидность текущей сессии Telegram |
| ffmpeg | Наличие в PATH (нужен для конвертации аудио перед транскрипцией) |
| Диск | Свободное место в домашней директории |

## Индикаторы

- ✅ — компонент в порядке
- ⚠️ — есть предупреждение (не критично, но ограничивает функциональность)
- ❌ — проблема, требующая решения

## Пример вывода

```
✅ Python 3.11.9
✅ Конфиг: /home/user/.tg_exporter/config.json (OK)
✅ Состояние: /home/user/.tg_exporter/state.json (OK)
⚠️  Keyring: недоступен (headless)
✅ Сессия: валидна
✅ ffmpeg: /usr/bin/ffmpeg
✅ Место на диске: 45.2 GB свободно в /home/user
```

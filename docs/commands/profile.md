# profile — Управление профилями

**Назначение:** Управление несколькими аккаунтами Telegram.

Профиль — это связка номера телефона, API ID и имени. Позволяет переключаться между разными аккаунтами без повторного входа. Каждый профиль хранит собственную сессию.

## Команды

### `profile list`

Список сохранённых профилей с отметкой активного.

Вывод: телефон, имя, API ID, статус (▶ активный).

### `profile add`

Добавляет новый профиль и делает его активным. После добавления требуется выполнить `auth login` для входа.

| Опция | Назначение |
|-------|-----------|
| `--phone` | Номер телефона (обязательно, +7999...) |
| `--api-id` | Telegram API ID (обязательно) |
| `--api-hash` | Telegram API Hash (обязательно) |
| `--name` | Отображаемое имя профиля |

### `profile remove`

Удаляет профиль и связанную с ним сессию.

| Опция | Назначение |
|-------|-----------|
| `--phone` | Номер телефона профиля (обязательно) |

### `profile switch`

Переключает активный профиль. Последующие команды будут выполняться от имени выбранного аккаунта.

| Опция | Назначение |
|-------|-----------|
| `--phone` | Номер телефона профиля (обязательно) |

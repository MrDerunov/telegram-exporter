# auth — Аутентификация в Telegram

**Назначение:** Управление входом в аккаунт Telegram и проверкой сессии.

Группа команд для полного цикла аутентификации: вход по номеру телефона, проверка статуса, выход, экспорт сессии для CI/CD, проверка валидности сессии.

## Команды

### `auth login`

Интерактивный вход в аккаунт Telegram.

- Запрашивает API ID / API Hash (если не переданы через опции или не сохранены в секретах)
- Запрашивает номер телефона (если не передан)
- Отправляет код подтверждения через Telegram
- Поддерживает 2FA (пароль)
- Сохраняет сессию после успешного входа

| Опция | Назначение |
|-------|-----------|
| `--phone` | Номер телефона (+7999...) |
| `--api-id` | Telegram API ID |
| `--api-hash` | Telegram API Hash |

### `auth status`

Проверяет, авторизован ли текущий аккаунт.

### `auth logout`

Выход из аккаунта — удаляет сессию.

### `auth export-session`

Экспортирует строку сессии в файл `secrets.exported.env` для использования в CI/CD.

Формат выдачи — переменные окружения: `TG_EXPORTER_API_ID`, `TG_EXPORTER_API_HASH`, `TG_EXPORTER_SESSION`.

| Опция | Назначение |
|-------|-----------|
| `--output` | Путь к выходному файлу (default: `secrets.exported.env`) |

### `auth verify`

Проверяет валидность сессии. Подходит для CI/CD пайплайнов.

Exit codes:
- `0` — сессия валидна
- `1` — сессия невалидна или отсутствует

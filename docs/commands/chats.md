# chats — Управление чатами

**Назначение:** Просмотр диалогов Telegram и управление списком чатов для экспорта.

Позволяет исследовать доступные чаты (с фильтрацией по папкам и поиском), просматривать информацию о конкретном чате, добавлять чаты в конфиг для быстрого экспорта и удалять их.

## Команды

### `chats list`

Показывает список диалогов из Telegram.

- Табличный вывод: ID, название, тип (user/group/channel/chat), папка
- Фильтрация по папке Telegram (`--folder`)
- Поиск по названию (`--search`)
- Режим просмотра только папок (`--folders`)

| Опция | Назначение |
|-------|-----------|
| `--folder` | Показать чаты в указанной папке Telegram |
| `--folders` | Показать только список папок |
| `--search` | Поиск по названию чата |

### `chats show`

Детальная информация о конкретном чате: название, ID, тип, дата последнего сообщения.

| Опция | Назначение |
|-------|-----------|
| `--chat` | ID чата (обязательно) |

### `chats add`

Добавляет чат(ы) в конфиг (`state.json`). Чат попадает в список для экспорта через `export --all`.

- Добавление одного чата по ID (`--chat`)
- Массовое добавление всех чатов из папки Telegram (`--folder`)

| Опция | Назначение |
|-------|-----------|
| `--chat` | ID чата |
| `--folder` | Добавить все чаты из папки Telegram |

### `chats remove`

Удаляет чат из конфига. Не влияет на ранее экспортированные данные.

| Опция | Назначение |
|-------|-----------|
| `--chat` | ID чата (обязательно) |
